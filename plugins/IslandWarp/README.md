# IslandWarp 1.0.0

原创单服玩家地标插件，面向 Lophine/Folia 与 BentoBox/BSkyBlock 空岛。
参考公共地标产品的功能需求，未使用 PlayerWarp 源码、资源或授权验证。

## 使用

`/iw` 打开六行导航菜单。支持分类、搜索、收藏、个人地标、管理员页面。
点击创建，在聊天中输入名称后选择分类，使用玩家确认时所在的位置。
聊天输入 60 秒过期，输入 `cancel` 取消。
点击地标打开详情；可传送、收藏，所有者可改名、改描述、改图标、分类、公开状态及位置。
删除必须通过确认页面。当前按钮和布局由代码定义，分类、标题、限制及传送参数由配置定义。
导航采用顶部筛选工具栏、最多 7 个精选推荐位、首页每页 21 个地标及底部导航；其他列表每页 28 个。
“清除搜索”保留分类，“重置全部筛选”同时清除关键词与分类；从详情返回保留列表页码与筛选。
普通导航没有管理入口，即使是 OP 也需要单独执行 `/iw admin` 打开管理中心。
管理中心内点击地标详情的“设置精选置顶”选择推荐位；也可执行 `/iw admin pin ID 1至7`（不超过配置位数），填 0 取消。
占用的推荐位会被替换，同一地标只能占一个推荐位。隐藏地标在普通菜单的精选区不显示。
精选区独立展示管理员推荐，不受当前列表的搜索、分类筛选影响。
置顶保存在 SQLite，旧数据库自动新增 pins 表，删除地标同步清理置顶。
分类菜单支持分页；新建坐标默认使用分类图标，修改分类不会覆盖已有图标。

- `/iw create 名称 [分类ID]` 创建；默认分类 other。
- `/iw me` 我的地标，`/iw favorites` 收藏，`/iw search 关键词` 搜索。
- `/iw tp 名称或ID` 传送，`/iw favorite ID` 收藏开关。
- `/iw edit ID name|description|category|icon|visible|location 内容` 编辑。
- 编辑 location 不需要内容；description 填 `-` 清空；visible 填 true 或 false。
- `/iw delete ID` 打开删除确认。
- `/iw admin` 查看所有地标，包括隐藏地标；`/iw status` 查看数据库。
- `/iw reload` 重载配置，`/iw help` 查看帮助。

普通玩家默认拥有 islandwarp.use 和 islandwarp.create，管理员权限 islandwarp.admin 默认仅 OP。
管理员入口对普通玩家隐藏，执行管理操作时再次校验权限。
管理员操作集中在独立管理视图，普通地标详情仅显示所有者自己的编辑工具。
普通玩家默认最多 5 个地标，只允许岛屿成员在自己的 BentoBox 岛屿保护范围内创建。
BentoBox 未连接时插件不会启用（plugin.yml 声明 depend）。管理员可以绕过成员和数量限制，不能绕过世界黑名单。

## 传送与存储

### 金币与状态交互

通过 Vault 连接 CMI 等经济实现；默认创建费用 100 金币，购买/续费推荐位 1000 金币，默认有效期 30 天；管理员置顶为永久。
创建和推广需要付款确认；重复购买操作有处理中锁，抢位/保存失败申请退款。
取消推荐或删除地标不退创建与推广费；管理员可以替换玩家购买的推荐位。
门票默认关闭，所有者可设置价格并切换收费；单次上限默认 10000 金币。
访客先确认票价，经过准备延迟、区块加载和安全检查后才扣款，传送失败申请退款。
岛主访问自己的地标免费，门票默认征税 5%，访客支付 100 时岛主收到 95，税款回收。
公开、收藏、门票收费按钮使用不同材质显示开/关，保存成功刷新详情。
支持点击、成功、失败、传送音效，配置可关闭或替换。
权威配置模板为 src/main/resources/config.yml，根目录配置参考.yml 是同步副本，构建检查一致性；启动自动生成 config-reference.yml，不覆盖现有 config.yml。
评分固定为 1–5 星；旧配置里的 ratings.min-stars/max-stars 不生效，重载保留用户原文件中的旧键，但新模板不再提供。
可配置金币费用、税率、票价上限、传送延迟与冷却、倒计时、移动/伤害取消、界面强调色、状态材质和音效。
仍使用原版箱子界面，布局与多数按钮文案由代码定义，并非全部 GUI 元素均可配置。
Vault 与 SQLite 无法共享原子事务：异常断电可能中断扣费与保存/退款，退款或岛主入账失败会记录需人工处理的 UUID 与金额。
已在隔离测试服用真实 Folia 假人、Skyllia 与 CMI 验证创建扣费、成功跨世界付费传送和税后入账；退款故障、离线岛主收款及真人客户端交互不因此视为全部验收。

默认准备 3 秒，移动或受伤取消，成功后冷却 10 秒；退出重连保留未到期冷却，服务器重启不保留。
使用玩家实体调度器、目标区域调度器、异步区块加载和 teleportAsync。
落点检查实心支撑、脚部与头部空间、危险方块、世界边界与高度。
位置不安全时拒绝传送，由岛主更新地标；不随机移动到附近其他岛屿。
岛屿关闭、删除、封禁和位置越界会阻止访问。
BentoBox 没有“岛屿私有/不开放访客”开关，访客限制依赖岛屿等级与保护标志，本插件只校验封禁。
落点检查与实际传送之间存在很短的时间窗口，其他玩家仍可能修改落点方块。

SQLite 驱动内置，数据位于 plugins/IslandWarp/islandwarp.db。
数据库专用线程串行执行，修改缓存数据的操作提交后刷新，纯查询和通知确认跳过全量刷新，关服等待任务队列完成。
提交后缓存刷新失败会记录故障，但不会返回可退款的保存失败；缓存恢复前拒绝新的创建、收费和权限敏感操作，下一个数据库任务先重试恢复。
正常停服后备份整个插件目录。不能将测试数据库复制到正式服。
支持固定 1–5 星评分、收藏、留言/回复、通知中心、举报、黑名单、回收站、收入统计、冻结/落点检测及活动时间；没有 MySQL 或跨服功能。
`/iw filters 最高票价或- 最低评分` 组合筛选；`/iw event ID yyyy-MM-ddTHH:mm yyyy-MM-ddTHH:mm` 设置活动，`off` 取消。
`/iw notices` 查看通知；`/iw trash` 与 `/iw restore ID` 管理回收记录；`/iw income` 查看更新后门票收入。

## PAPI

无需安装额外 expansion，安装 PlaceholderAPI 后自动注册。

| 变量 | 内容 |
|---|---|
| %islandwarp_total% | 公开地标数 |
| %islandwarp_num% | 当前玩家拥有的地标数 |
| %islandwarp_favorites% | 当前玩家可查看的收藏数 |
| %islandwarp_visits% | 当前玩家地标累计访问次数 |
| %islandwarp_database_status% | 数据库状态 |
